## Easy App Maker 是什么？

**Easy App Maker（简易应用制作器）** 是一个专为非程序员设计的 AI 驱动应用生成平台。

它不是传统的"无代码工具"——那些工具虽然不用写代码，但你得学会它们复杂的拖拽界面和配置逻辑。

**Easy App Maker 更简单：你只需要"说话"。**

## 技术特性（给懂一点技术的人）

### 生成的代码技术栈
- **前端**：HTML5 + Tailwind CSS (CDN) + Vanilla JavaScript
- **数据可视化**：Chart.js（仪表盘）
- **动画**：CSS Transitions + 自定义动画
- **响应式**：Mobile-first 设计，完美适配所有设备

### 为什么选择这个技术栈？
1. **零依赖**：无需 npm、webpack、babel
2. **即开即用**：双击 HTML 文件就能运行
3. **易于学习**：代码结构清晰，适合后续学习
4. **部署简单**：任何静态托管服务都支持

### AI 能力支持
- **多模态大模型**：Claude 3.5 Sonnet / Gemini Pro
- **代码生成**：遵循最佳实践和现代标准
- **文档生成**：专业排版和数据分析
- **内容创作**：平台特性优化和 SEO 友好
