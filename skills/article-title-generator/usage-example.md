# 公众号文章标题生成器使用示例

## 基本使用方法

### 1. 直接输入文章内容

```
/generate-titles content "您的文章内容..."
```

示例：
```
/generate-titles content "在数字化时代，人工智能正在改变企业的运营方式..."
```

### 2. 读取Markdown文件

```
/generate-titles file /path/to/article.md
```

示例：
```
/generate-titles file ./test-article.md
```
